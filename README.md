# Danish Khan — Portfolio Website

A modern, character-driven personal portfolio website for Full-Stack Software Engineer **Danish Khan**, built with **Next.js (App Router)**, **Tailwind CSS**, and **Framer Motion**.

Designed with inspiration from clean, minimal developer portfolio aesthetics, featuring floating 3D Bitmoji animations, a persistent profile sidebar, web-native interactive resume, and filterable project showcases.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI & Styling**: Tailwind CSS, PostCSS, Lucide React
- **Animations**: Framer Motion
- **Typography**: Plus Jakarta Sans
- **Language**: TypeScript

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Danishthinks/my-portfolio.git

# Navigate to project directory
cd my-portfolio

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## 📄 Pages Included

- **`/` (About / Home)**: 2-column desktop / stacked mobile Hero with 3D floating Bitmoji, glowing pastel blob, performance metrics, and specialty service cards.
- **`/resume`**: Web-native resume layout featuring work experience timeline, university education, certifications, and technical skills grid.
- **`/projects`**: Category-filtered project cards with modern CSS gradient covers, Lucide icons, and live production URLs.
